# Source assumptions for the queueing model

## Meaning of the all-request fraction

- **All-request fraction → stationary probability/intensity interpretation**
  for the display in “A Queuing Model for the Inspection Scheduling Process.”
  If admitted rate is $s_{k,b}$, raw rate $\lambda_{k,b}>0$, and a stationary
  typical admitted request is timely with probability at least $1-\alpha$,
  the timely all-request intensity fraction is at least
  $(s_{k,b}/\lambda_{k,b})(1-\alpha)$. Convergence of empirical fractions
  along raw arrival paths is not proved by this statement.
